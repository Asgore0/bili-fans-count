# Security Policy

## Supported Versions

The current `main` branch is the supported development line.

## Reporting

For non-sensitive issues, open a GitHub issue with reproduction steps and the app version.

For sensitive reports, avoid posting tokens, cookies, private account data, or personal contact information in public issues. Use a private channel with the maintainer if one is listed on the GitHub repository.

## Data Handling

This app calls public Bilibili APIs from the user's device and stores settings/history locally. It does not include a hosted backend service.
